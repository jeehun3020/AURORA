# AURORA 분석 및 AI 모델링 계획

## 1. 프로젝트 목표

**AURORA — Arctic Underwriting & Route Operational Risk Assessment**

공개 해빙·기상·AIS 데이터를 활용하여 북극해항로(NSR)의 날짜·구간·선박 조건별 운항위험을 계산하고, 안전조치 적용 후 남는 **잔여위험**과 **상대 보험 할증 방향**을 제시하는 의사결정 지원 프로토타입을 개발한다.

> POLARIS가 "갈 수 있는가?"를 묻는다면, AURORA는 "어떻게 가야 위험과 보험 부담을 가장 줄일 수 있는가?"를 답한다.

본 프로젝트는 실제 보험료 예측이나 POLARIS 대체를 목표로 하지 않는다. POLARIS 기반 해빙위험에 기상, 구조 접근성, 선박 특성, 운항지원과 안전조치를 결합한 확장형 상대위험 모델을 제안한다.

## 2. 분석 범위

- 기간: 2015~2024년
- 항행시즌: 7~10월
- 해역: 카라해, 랍테프해, 동시베리아해, 추크치해
- 선박: 화물선 중심
- 주요 비교 조건
  - PC6와 PC7
  - 쇄빙선 지원 유무
  - 즉시 출항과 출항 연기
  - 기존 항로와 우회 항로
  - 구조기지 인접 구간과 원거리 구간

## 3. 핵심 모델 구조

```text
POLARIS 기반 해빙위험
+ 기상위험
+ 선박 취약도
+ 극지 구조공백
= 고유위험

고유위험
× 안전조치 적용효과
= 잔여위험

잔여위험
→ 상대 보험 할증계수
→ 안전조치 크레딧
```

```text
사고가능성 P
= f(해빙, 파고, 풍속, 저온, 선박등급, 쇄빙지원)

사고결과 S
= g(구조기지 거리, 피난항, 선박·화물 특성)

고유위험
= P × S

잔여위험
= 고유위험 × 극지손실증폭(PRGI) × (1 - 안전조치 효과)

상대 할증계수
= 1 + α × 정규화된 잔여위험
```

## 4. 데이터 현황

### 4.1 NSIDC 해빙

NSIDC G02135 Version 4 북극 지역별 일별·월별 해빙자료를 확보했다.

- 지역별 일별 해빙면적(Area)과 해빙범위(Extent)
- 지역별 월평균 해빙면적과 해빙범위
- 기간: 1978~현재
- 분석 대상: 카라·랍테프·동시베리아·추크치해

저장 위치:

```text
nsr_analysis/nsidc_data/
├─ N_Sea_Ice_Index_Regional_Daily_Data_G02135_v4.0.xlsx
└─ N_Sea_Ice_Index_Regional_Monthly_Data_G02135_v4.0.xlsx
```

주요 파생변수:

```text
해빙밀집도 = Area / Extent
1981~2010 평년 대비 편차
동일 날짜 기준 과거 백분위
연도별 최저 해빙값
최저 해빙 발생일
저해빙 상태 지속일수
```

주의: 이 자료는 지역 단위의 해빙면적·범위 자료다. 정식 POLARIS 계산에는 해빙 유형·연령과 선박 등급별 RIO 자료가 추가로 필요하다.

### 4.2 EIA 국제유가

- WTI: 2010~2025년, 4,017행
- Brent: 2010~2025년, 4,049행
- NSR 통항량 변화의 경제적 통제변수로 활용

### 4.3 NSR 통항 실적

현재 2011~2025년 자료가 있으나 다음 연도가 누락되어 있다.

```text
2014, 2017, 2019, 2020, 2021, 2022
```

CHNL의 연도별 NSR Transit Statistics에서 재수집해야 한다. 통계마다 항차수, 고유선박수, 전체통과 여부와 공간범위를 명시한다.

### 4.4 ERA5 기상·해양

다운로드 스크립트가 작성되어 있다. CDS 토큰 설정 후 다음 변수를 수집한다.

- 2m 기온
- 2m 이슬점
- 10m U·V 바람성분
- 유의파고
- 해빙농도

### 4.5 AIS

PAME ASTD 이용 승인을 기다리고 있다. 승인 후 다음 선박행동을 위험 검증지표로 사용한다.

- 비정상 감속
- 장시간 정지·대기
- 항로 이탈·우회
- 구간 통과시간 증가
- 쇄빙선 동행

## 5. 분석 계획

### 5.1 NSIDC 전처리

원본 Excel은 변경하지 않고 다음 형태의 정제 데이터를 별도로 생성한다.

```text
date | region | area_km2 | extent_km2 | compactness
```

이후 2015~2024년 7~10월과 NSR 4개 해역을 추출한다.

### 5.2 해빙 패턴 분석

- 해역별 장기 해빙 변화
- 7~10월 해빙 감소·재결빙 패턴
- 최근 10년과 1981~2010 평년 비교
- 해역별 최저 해빙값과 발생일
- 해역별 저해빙 상태의 시작·종료 시점
- Area와 Extent 차이 및 밀집도 변화

통계 방법:

- Mann–Kendall 추세검정
- Sen's slope
- GAM
- Spearman 상관분석
- 시계열 분해

### 5.3 지역 해빙 부담지표

각 해역·날짜의 해빙 상태를 과거 같은 날짜의 분포와 비교하여 백분위 또는 표준점수로 변환한다.

```text
Regional Ice Burden
= 해당 날짜의 해빙 수준이 과거 동일 날짜 분포에서 차지하는 위치
```

이 값은 POLARIS 점수가 아니라 **지역 해빙 부담 대리지표**로 표현한다.

### 5.4 ERA5 결합

다음 기상 파생변수를 생성한다.

- 풍속
- 유의파고
- 기온
- 이슬점–기온 차이
- 해빙농도
- 극저온 여부
- 고파고·강풍 임계값 초과 여부

### 5.5 통항량과 경제변수 결합

CHNL 누락 연도를 보완한 뒤 다음 관계를 분석한다.

```text
항행시즌 평균 해빙 ↔ NSR 통항 횟수
9월 최저 해빙 ↔ NSR 통항 횟수
국제유가 ↔ NSR 통항 횟수
해빙 + 유가 + 제재 시기 ↔ 통항 변화
```

상관관계 결과를 인과관계로 표현하지 않는다.

## 6. AI·머신러닝 계획

### 6.1 AIS 확보 전

현재는 선박 위험행동에 대한 정답 데이터가 없으므로 운항위험 지도학습 모델을 바로 학습하지 않는다.

가능한 분석:

- SARIMAX/GAM: 해빙 시계열 기준모델
- XGBoost: 해빙조건 예측
- 군집분석: 해빙환경 패턴 구분
- Isolation Forest: 비정상 해빙환경 탐지

군집이나 이상탐지 결과를 실제 운항위험으로 단정하지 않고 **해빙환경 패턴 또는 이상상태**로 표현한다.

### 6.2 AIS 확보 후

```text
입력
├─ 해빙 면적·범위·밀집도
├─ ERA5 파고·풍속·기온·해빙농도
├─ 선박 등급·선종
├─ 구조 접근성·쇄빙지원
└─ 해역·계절·시간

정답
├─ 비정상 감속 여부
├─ 장시간 대기 여부
├─ 우회 여부
└─ 구간 통과시간 증가량
```

추천 모델:

1. 로지스틱 회귀 또는 GAM: 설명 가능한 기준모델
2. XGBoost 또는 LightGBM: 주력 비선형 모델
3. SHAP: 변수별 위험 기여도 설명
4. 확률 보정: 위험행동 발생확률과 신뢰도 평가

검증 방법:

- 시간순 학습·검증 분리
- 선박별 GroupKFold
- Leave-One-Year-Out 검증
- ROC-AUC와 PR-AUC
- Brier Score와 calibration curve

LSTM과 Transformer는 현재 범위에서 우선 사용하지 않는다. 기준모델보다 실제 성능이 좋아지는지 검증되는 경우에만 추가한다.
