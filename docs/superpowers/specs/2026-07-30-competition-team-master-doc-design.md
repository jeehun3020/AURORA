# 대회 제출용 팀 마스터 문서 설계

## 목적

팀원이 AURORA의 분석 결과를 동일하게 이해하고, 분석보고서·PPT·발표 대본·질의응답을 만들 때 하나의 기준문서로 사용할 수 있는 Markdown 파일을 작성한다.

최종 문서는 `docs/07_competition_submission_master.md`에 저장한다.

## 독자

- 대회 준비팀 내부 구성원
- 분석을 직접 수행하지 않은 팀원도 이해할 수 있어야 한다.
- 심사위원에게 전달할 문장을 작성하는 팀원이 수치와 주장 수준을 빠르게 확인할 수 있어야 한다.

## 핵심 설계 원칙

1. **결과 중심**: 가장 강한 제출 결과를 문서 앞부분에 배치한다.
2. **근거 추적 가능**: 모든 핵심 수치에 데이터 범위·표본·해석 범위를 함께 적는다.
3. **주장 수준 분리**: 견고, 모델 내 견고, 유망, 가정, 판단 불가를 명시한다.
4. **과장 방지**: 상대 위험지수를 실제 사고확률·보험료로 표현하지 않는다.
5. **실무 활용성**: 보고서와 발표자료에 바로 옮길 수 있는 문구·표·스토리라인을 포함한다.
6. **중복 최소화**: 기존 문서의 내용을 단순 복사하지 않고, 제출 판단에 필요한 정보만 통합한다.

## 문서 구조

### 1. 문서 사용법

- 이 문서가 팀 내부 단일 기준문서임을 명시
- 수치의 지위와 표현 규칙 설명
- 분석기간과 데이터 범위 요약

### 2. 한눈에 보는 최종 결론

- 제출 가치가 높은 핵심 결과 5~7개
- 각 결과의 핵심 수치, 근거 수준, 제출에서의 역할
- 가장 추천하는 한 문장 결론

### 3. 추천 제출 스토리라인

- 문제 정의
- 기존 접근의 한계
- AURORA의 분석 질문
- 발견
- 의사결정 적용
- 검증
- 한계와 향후 검증

### 4. 핵심 결과 상세

다음 결과를 우선순위 순으로 설명한다.

1. 시즌 후반 3일 연기의 위험 증가
2. 평균·중앙값 부호 불일치와 꼬리위험
3. 네 구간 공통 저위험 출항창
4. 3·7일 예측 기반 출항규칙의 롤링 외표본 성능
5. 동시베리아해 항행가능성 병목
6. PC6·PC7 차이가 중간 빙조건에 집중되는 비단조성
7. ERA5·NSIDC·ARAON 외부검증
8. ARAON 센서 결함 탐지

각 절에는 정의, 표본, 핵심 수치, 의미, 제출용 문장, 제한사항을 포함한다.

### 5. 모델 구조 감사

- 해빙의 평균수준 기여와 변동 기여
- PRGI가 추크치해 순위를 바꾸는 과정
- 파고 결측 처리 민감도
- 2015~2024 복합위험 추세가 불확실하다는 결과

### 6. 데이터 품질 및 기존 문서 정정

- ERA5·NSIDC·ARAON·통항자료의 행 수와 기간
- ARAON 전체 매칭 2,528행과 기온 유효쌍 2,450의 구분
- 검증 대상이 2020~2024의 5개 항차라는 점
- 구간별 매칭 수 정정
- NSR 통항자료 6개 연도 결측

### 7. 주장 가능 수준

- 단정 가능한 주장
- 범위로만 제시할 주장
- 조건부로 제시할 주장
- 제출에서 제외할 주장

### 8. 보고서·PPT 작성 재료

- 제목 후보
- 초록용 요약문
- 결과 섹션용 문단
- 슬라이드 구성안
- 핵심 도표와 사용 목적
- 예상 심사 질문과 답변

### 9. 남은 작업과 우선순위

- PAME ASTD 화물선 AIS 행동검증
- PRGI 실증자료 보강
- 실제 항로선·구간 통과시차 반영
- CHNL 누락 연도 보완
- POLARIS 공식 RIO 구조 반영

## 표현 기준

- 퍼센트 변화는 평균·중앙값·강건 통계 중 무엇인지 명시한다.
- 상관관계를 인과관계로 표현하지 않는다.
- “보험료 예측” 대신 “상대위험 및 할증 방향을 제시하는 프로토타입”을 사용한다.
- 예측모델의 개선율은 실제 사고 감소가 아니라 잠정 위험지수의 실현값 감소로 설명한다.
- PRGI와 쇄빙지원 효과는 실증결과가 아니라 가정 기반 시나리오임을 표시한다.

## 검증 기준

- 핵심 수치가 심층 분석 CSV와 일치해야 한다.
- ARAON 표본수와 연도 정의가 정정된 값과 일치해야 한다.
- 미확정 표식이나 임시 문구가 없어야 한다.
- 동일 결과가 서로 다른 절에서 상충하지 않아야 한다.
- 팀원이 핵심 결론, 사용 가능한 표현, 남은 약점을 5분 안에 파악할 수 있어야 한다.
