# AURORA 대회 제출용 팀 마스터 문서

> **용도**: 팀원이 분석보고서·PPT·발표 대본·심사 질의응답을 만들 때 사용하는 내부 단일 기준문서
> **최종 갱신**: 2026-07-30
> **주의**: 이 문서의 위험은 실제 사고확률이나 보험료가 아니라 현재 AURORA 잠정 상대위험지수다.

---

## 0. 이 문서 사용법

이 문서는 AURORA에서 대회에 제출할 가치가 있는 결과를 한곳에 모으고, 각 결과가 어디까지 검증됐는지를 구분한다. 팀원은 보고서나 발표자료를 작성할 때 다음 순서로 사용한다.

1. 먼저 `1. 한눈에 보는 최종 결론`에서 제출의 중심 결과를 확인한다.
2. 수치를 사용할 때는 해당 상세 절의 정의·표본·제한사항을 함께 확인한다.
3. 문장을 작성할 때는 결과의 근거등급과 `제출용 문장`을 따른다.
4. 실제 사고율·보험료·인과효과처럼 검증되지 않은 내용은 `제출에서 금지할 주장`을 따른다.
5. 서로 다른 문서의 수치가 충돌하면 이 문서의 정정표와 심층 분석 결과를 우선한다.

### 0.1 분석 범위

| 구분 | 범위 |
|---|---|
| ERA5 위험분석 | 2015~2024년, 매년 7~10월, 4개 해역, 일별 4,920행 |
| NSIDC 장기 해빙 | 완결연도 1979~2025년, 카라·랍테프·동시베리아·추크치해 |
| ARAON 원자료 | 2020~2025년 6개 항차, 시간별 QC 12,189행 |
| ARAON–ERA5 외부검증 | ERA5 기간과 겹치는 2020~2024년 5개 항차, 전체 매칭 2,528행 |
| 단기예측 롤링 검증 | 2020~2024년을 한 해씩 미관측 연도로 설정 |
| NSR 통항자료 | 2011~2025년 중 6개 연도 결측, 통계적 상관결론에 사용 불가 |

### 0.2 근거등급

| 등급 | 의미 | 사용 원칙 |
|---|---|---|
| **A — 견고** | 관측자료나 데이터 품질로 직접 확인 | 정의와 범위를 붙여 단정 가능 |
| **A — 모델 내 견고** | 여러 민감도 분석에서 방향 유지 | 현실 검증과 구분해 방향 단정 |
| **B — 유망** | 외표본 또는 반복성 검증을 통과 | 잠정 지수 내부 결과로 표현 |
| **C — 가정 의존** | 미검증 가정이 순위·크기를 결정 | 조건부 시나리오로만 표현 |
| **판단 불가** | 자료 부족 또는 구조적 교란 | 제출의 결과 주장으로 사용 금지 |

### 0.3 통계 표기 원칙

- 퍼센트 변화가 산술평균인지 중앙값인지 반드시 적는다.
- 일별 관측을 모두 독립표본으로 간주하지 않고 연도 또는 연도×구간 군집 불확실성을 함께 본다.
- 가중치 민감도는 “가중치가 옳다”는 증거가 아니라 “가중치가 바뀌어도 방향이 유지되는가”의 검사다.
- `모델 내 견고`는 실제 사고위험이 검증됐다는 뜻이 아니다.
- 상관관계와 사례 반증을 인과효과로 바꾸어 말하지 않는다.

## 1. 한눈에 보는 최종 결론

### 1.1 제출 가치가 높은 결과

| 우선순위 | 결과 | 핵심 수치 | 근거등급 | 제출에서의 역할 |
|---:|---|---|---|---|
| 1 | 시즌 후반 3일 연기는 위험지수를 높인다 | 9월 평균 **+14.0%**, 연도 군집 95% 구간 **+10.0~+18.3%**; 10월 **+16.1%**, **+12.0~+20.6%** | A — 모델 내 견고 | 가장 강한 핵심 발견 |
| 2 | 연기 효과는 평균과 중앙값이 다른 꼬리위험 구조다 | 전체 평균 **+7.2%**, 중앙값 **−0.7%**, 5~95% 윈저평균 **+4.1%** | A — 견고 | 보험·운항 의사결정 차별점 |
| 3 | 네 구간의 반복 가능한 공통 저위험 창이 존재한다 | **9월 13~17일**, 네 구간 평균위험 최저일 **9월 15일** | B — 모델 의존 | 실행 가능한 출항창 제안 |
| 4 | 단기예측으로 더 낮은 지수 상태를 선택할 수 있다 | 3일 규칙 평균 **5.6%**, 7일 규칙 **7.4%** 개선; 2020~2024 모든 평가연도 양수 | B — 유망 | 의사결정 프로토타입의 내부 후향검증 |
| 5 | NSR 완주 가능성은 구간 병목이 결정한다 | 동시베리아해 최근 5년 항행가능일 **53일**, 카라해 **121일**의 44% | A — 견고 | 구간별 모델의 필요성 |
| 6 | 현재 위험지수는 해빙이 지배한다 | 평균 위험수준의 **51.0%**, 일별 변동의 **81.7%**가 해빙 | A — 구조 감사 | 모델 정직성·추가검증 필요성 |
| 7 | ARAON 센서 결함을 독립적으로 탐지했다 | 기압 유효율: 2023년 **1.6%**, 2024·2025년 **0%** | A — 견고 | 공공데이터 품질 개선 성과 |
| 8 | 추크치해 최종순위는 PRGI 가정에 민감하다 | 환경위험 최저 **0.335** → SAR 거리 기반 45.4% 증폭 → 최종 **0.488**, 2위 | C — 가정 의존 | 모델 한계와 향후 검증 과제 |

### 1.2 가장 추천하는 한 문장

> **AURORA는 북극항로를 단순히 “갈 수 있는가”로 평가하는 대신, 구간별 병목과 꼬리위험을 반영해 “언제 출항해야 더 낮은 상대위험 상태를 선택할 수 있는가”를 제시하는 의사결정 지원 프로토타입이다.**

### 1.3 발표에서 반드시 먼저 인정할 세 가지

#### 현재 지수는 사실상 해빙 중심 지수다

현재 가중치와 임계값에서 해빙은 평균 위험수준의 51.0%, 일별 변동의 81.7%를 만든다. 심사위원이 “결국 그냥 해빙지수 아닌가?”라고 물으면 부인하지 않는다.

**권장 답변**

> 맞습니다. 현재 지수의 변동은 해빙이 지배합니다. 저희 분석은 이 사실을 숨기지 않고 정량화했습니다. 해빙 이외의 풍속·파고·저온·안개를 결합하는 추가가치가 실제 화물선의 감속·대기·우회를 더 잘 설명하는지는 아직 검증되지 않았으며, 이를 확인하려면 PAME ASTD 화물선 AIS가 필요합니다.

#### 추크치해 순위는 현재 SAR 거리 가정이 만든다

추크치해의 환경위험은 네 구간 중 최저인 0.335다. 그러나 현재 SAR 거리 기반 PRGI가 45.4%를 증폭해 최종위험 0.488, 2위가 된다.

**금지 표현**

> 추크치해는 NSR에서 두 번째로 위험한 구간이다.

**권장 표현**

> **현재 SAR 거리 기반 손실증폭 가정에서는** 추크치해의 사고결과 측 상대위험이 커져 최종순위가 2위로 올라간다.

#### 연간 위험 증가·감소 추세를 말할 수 없다

2015~2024년 연평균 복합위험의 선형추세는 네 구간 모두 통계적으로 불확실하다.

| 구간 | OLS p값 | 판정 |
|---|---:|---|
| 추크치해 | 0.45 | 불확실 |
| 동시베리아해 | 0.35 | 불확실 |
| 카라해 | 0.46 | 불확실 |
| 랍테프해 | 0.89 | 불확실 |

따라서 “AURORA 위험이 증가하고 있다” 또는 “기후변화로 위험이 감소하고 있다”는 문장은 사용하지 않는다. 장기 해빙의 감소와 2015~2024년 복합운항위험의 추세는 서로 다른 분석이다.
